MIPS8 Processor.

A transistor-level implementation of a microprocessor for MIPS8 assembly instructions.

GitHub files Back to projects

Built for my integrated circuits class, this project implements the microprocessor for MIPS8 assembly instructions using Electric VLSI.

The work went down to transistor level: schematic construction, layout, and verification. The chip was tested with .cmd command files and assertions to confirm the design behaved as intended.
