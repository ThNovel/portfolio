ASIC

Similarity Detector.

A simple combinational ASIC that compares two 8-bit inputs against a threshold.

GitHub files Back to projects

This was the final project for my integrated circuits class. It is an ASIC that uses combinational logic for simplicity.

The circuit compares two inputs, x0..x7 and w0..w7. If the number of matching bits is greater than or equal to the input threshold b, the output becomes 1.
